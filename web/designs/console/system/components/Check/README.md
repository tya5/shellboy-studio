# Check

- **Use for:** Offer one explicitly labelled yes/no choice, with an optional consequence note.
- **Do not use for:** Use ChoiceList for one choice among several alternatives.
- **Why:** A native checkbox exposes its own state and the note can explain what will change.
- **Source:** 出典なし（この Studio で決めた）

A single checkbox with its label and an optional line under it. Use it for a choice that changes what a button does, such as confirming a replacement or making something the default; say in the label what checking it means, and put the consequence in `note`. For one option out of several use ChoiceList.

Styles: style.css in this directory
