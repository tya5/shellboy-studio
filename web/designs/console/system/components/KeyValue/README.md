# KeyValue

- **Use for:** Show reported label/value pairs in Thread details; use `code` for paths, numbers and models.
- **Do not use for:** Use FactList when missing facts need explicit wording or notes, and SettingRow to edit settings.
- **Why:** Omitting an unreported pair avoids implying a guess or an owner-provided value.
- **Source:** 出典なし（この Studio で決めた）
