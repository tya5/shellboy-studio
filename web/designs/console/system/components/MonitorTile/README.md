# MonitorTile

- **Use for:** Watch a small selection in equal edge-separated panes with a Thread link, independent pin and clipped tail.
- **Do not use for:** Use ThreadCard to scan many Threads or Conversation for a scrollable transcript.
- **Why:** A fixed, bottom-aligned preview keeps current activity visible without introducing a scroller per pane.
- **Source:** [Studio Monitor cards and panes](../../../../../../docs/design/monitor-tiles.md)

A border-separated monitor pane. The header contains a conversation link and independent pin control. The flexible body links to the conversation, clips overflowing lines from the top, and keeps the supplied status at the bottom. Use inside a fixed-size pane grid; no pane scrolling or rounded card styling.

Styles are colocated in `system/components/MonitorTile/style.css`.
