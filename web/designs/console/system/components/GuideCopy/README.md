# GuideCopy

- **Use for:** Show the exact AGENTS.md guidance and offer Copy.
- **Do not use for:** Use SettingRow to edit a setting; this component never writes files.
- **Why:** Keeping the text selectable gives a direct fallback when clipboard access fails.
