# QuestionItem

- **Use for:** Show one pending question's Thread, age and text in an Awaiting you list and open its QuestionCard.
- **Do not use for:** Use QuestionCard to answer, not QuestionItem; use ThreadItem for ordinary Thread navigation.
- **Why:** A compact row is scannable and leaves the answer controls to the selected question.
- **Source:** 出典なし（この Studio で決めた）

One question in the Awaiting you list: Thread title, age and the question. The current one takes the `wait` ground. It opens the QuestionCard.

Styles are colocated in `system/components/QuestionItem/style.css`.
