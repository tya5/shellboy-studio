# ThreadMovePicker

Provides the existing parent picker and preview/confirmation flow for a single Thread. Its candidate list is bounded and scrollable so it cannot displace the page on phone layouts.

- **Place:** open from the sidebar row menu's existing Move action, near that Thread's row.
- **Do not use for:** bulk reparenting or a separate Threads destination; #138 removes those screens and keeps Move as a per-Thread operation.

Styles: style.css in this directory.
