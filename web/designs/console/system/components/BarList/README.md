# BarList

- **Use for:** Compare a short set of ranked values on one neutral scale; always show the numbers.
- **Do not use for:** Use Meter for a budget and Chart for a trend.
- **Why:** One scale makes magnitudes comparable without giving category fills extra meaning.
- **Source:** 出典なし（この Studio で決めた）

A short ranked comparison, such as storage by category. All bars share one scale and one neutral fill; the number is always written. It isn't for values against a limit (use Meter) or over time (use Chart).

Styles are colocated in `system/components/BarList/style.css`.
