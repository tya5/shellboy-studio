# ButtonGroup

- **Use for:** Choose one of a few short peer options, such as period, theme or language.
- **Do not use for:** Use ChoiceList when options need explanatory notes; use Button for independent actions.
- **Why:** Pressed state exposes the current choice and the row wraps on narrow frames.
