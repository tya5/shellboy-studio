# ListDivider

- **Use for:** Label an Activity category with an optional count and a thin rule.
- **Do not use for:** Use Disclosure for expandable content or Section for a page-level subject card.
- **Why:** A divider gives a flat list readable groups without making the heading interactive.
- **Source:** [UCL section grouping, as recorded in the Studio right-panel decision](https://github.com/tya5/shellboy-studio/commit/9907385bde52daee348d71b0293f53453bbb1390)
