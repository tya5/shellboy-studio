# Menu

A compact WAI-ARIA menu of short text actions opened from a button through
`Popover`. Follow shadcn/ui `DropdownMenu` (Radix) and the WAI-ARIA APG Menu
pattern: focus the first item on open, support arrow/home/end movement, close on
Escape/outside pointer, and keep destructive actions last. Use separators between
distinct kinds of action. Disabled entries are omitted. Do not put settings forms
or long data-entry controls in a menu.
