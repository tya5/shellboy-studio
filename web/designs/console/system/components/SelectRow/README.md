A Thread in a list that supports choosing several. The checkbox chooses and the title opens. Depth reflects a real parent link; `note` names a parent outside the group. `drag` is present only when moving a Thread is available. `moveAction` stays in place beside the title.

The optional menu trigger is in-flow. It follows the shadcn/ui `SidebarMenuAction` (`showOnHover`) states: hover, keyboard focus-visible inside, selection, and open on hover-capable devices; always visible on touch. The block title truncates before it. The row owns its menu state and anchor through `useRowMenu`.
