# RankedBar

Decorative horizontal stacked bar for a ranked table with exact values already present in text. Use a shared nonzero maximum per ranking and the same part order in each row and in the legend. Do not use it to present values without a table, or for time series. The label and bar stack in the phone container.

Pattern: [Datawrapper stacked bars](https://www.datawrapper.de/docs/how-to-create-a-stacked-bar-chart).

Styles: style.css in this directory
