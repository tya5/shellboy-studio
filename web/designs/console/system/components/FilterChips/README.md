# FilterChips

- **Use for:** Show removable active filters below the filter trigger and offer Clear all.
- **Do not use for:** Use Chip for counts that do not remove filters and FilterMenu to pick filters.
- **Why:** Keeping the active criteria visible lets people remove one or clear the set without reopening the picker.
- **Source:** [Studio Thread list (Orca, shadcn/ui, APG)](../../patterns/thread-list.md)

Removable Chip controls for active list filters, with one clear-all action.
Place them below the filter trigger. Use a plain status Chip for counts that do
not remove filters.

References: Orca sidebar filters and shadcn/ui Sidebar.

Styles: style.css in this directory
