# FilterChips

- **Use for:** Show removable active filters below the filter trigger and offer Clear all.
- **Do not use for:** Use Chip for counts that do not remove filters and FilterMenu to pick filters.
- **Why:** Keeping the active criteria visible lets people remove one or clear the set without reopening the picker.
