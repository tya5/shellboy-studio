## Consumer Ownership

under the existing revision/epoch/capability qualification. WindowedScroll begins
one S-owned transition from that actual capture, including native scroll capture.
A changed source reader can replace only its own same-revision registration; a
target scroll must not clear the prior source-to-target transition. Unmount clears
only the recorded owned ID. S owns loaded explicit membership, below-range order,
handle tokens, body-node qualification, source/target authority and slot limits.

The existing D AppModel.loadBody path is the only body receipt in the actual-model
control. It passes an existing strict historyGet result to S under original
handle/reader/nav/cancel qualification. G adds zero reads, no inferred source IDs
and no parsing of text, ordinal proximity or raw data.

The G root subscribes to acceptedView as well as existing version signals. This
matters because coverage publication can commit a new accepted ref without a
version increment. Callback work only invalidates presentation; it does not consume
or write scroll. Subscription is disposed with the root.

The single CurrentScrollSync measures the current target, rechecks exact current
qualification and consumes coverage once before writing. Inside resolves the
unique actual summary node; below resolves the surviving actual reader node. Delta
is target.top - viewport.top - saved.offset. Duplicate, hidden, closed-container,
missing or revoked target geometry rejects without coverage/Heading/scroll-request
consumption, scroll write or reader capture. Ordinary request and Heading plans are
not imported into the new transaction. Ordinary revision rejection stays intact.

There is one local source-registration record and one S transition slot (4096
explicit IDs). No new queue, timer, browser operation, RPC or public protocol API.
The helper scans only loaded DOM and retains no element. A remounted same-key item
is measured afresh, not described as retained DOM.
